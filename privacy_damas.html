DAMAS DO CAOS

Política de Privacidade
Última atualização: abril de 2026
Esta Política de Privacidade descreve como o jogo Damas do Caos, desenvolvido por Gabriel Mateus Nascimento de Oliveira, coleta, utiliza e protege as informações dos usuários. Ao usar o aplicativo, você concorda com as práticas descritas neste documento.
Artigo I

Dados Coletados

O aplicativo pode coletar os seguintes dados:

  • Nome ou apelido do jogador: usado exclusivamente para exibição no ranking online global.
  • Dados de desempenho: pontuação, vitórias, sequência de vitórias, reinos conquistados e posição no ranking.
  • Dados de progresso local: moedas virtuais, poderes desbloqueados, progresso no Modo Mundo — armazenados no dispositivo do usuário.
Artigo II

Como os Dados São Usados

Os dados são utilizados exclusivamente para:

  • Exibir o ranking global de jogadores
  • Registrar pontuações e progresso competitivo
  • Salvar o progresso do jogador entre sessões
  • Melhorar a experiência geral do jogo
Artigo III

Armazenamento e Segurança

Os dados do ranking são armazenados em infraestrutura segura na nuvem utilizando o Firebase Firestore (Google), com criptografia em trânsito.

Os dados de progresso local são armazenados exclusivamente no dispositivo do usuário e nunca transmitidos.

Artigo IV

Publicidade (Google AdMob)

O aplicativo pode exibir anúncios fornecidos pelo Google AdMob. O Google pode usar identificadores de dispositivo e dados de uso para exibir anúncios relevantes. Para mais informações, consulte a Política de Privacidade do Google.

Usuários que adquirirem o plano Premium não verão anúncios.

Artigo V

Compras dentro do Aplicativo

O Damas do Caos oferece compras opcionais por meio do Google Play Billing. As transações são processadas diretamente pelo Google. Não temos acesso a dados de pagamento.

Artigo VI

Compartilhamento de Dados

O Damas do Caos não vende nem compartilha dados pessoais com terceiros para fins publicitários ou de marketing.

Artigo VII

Contas de Usuário

O aplicativo não exige criação de conta, login ou autenticação formal. O apelido informado serve apenas para identificação no ranking global.

Artigo VIII

Dados de Crianças

O Damas do Caos não é direcionado especificamente a crianças menores de 13 anos. Não coletamos intencionalmente dados pessoais de crianças.

Artigo IX

Seus Direitos (LGPD)

De acordo com a Lei Geral de Proteção de Dados (Lei nº 13.709/2018), você tem direito a acessar, corrigir ou solicitar a exclusão dos seus dados.

Caso deseje remover seu nome do ranking, entre em contato com o desenvolvedor para exclusão manual.

Artigo X

Alterações nesta Política

Esta política poderá ser atualizada periodicamente para refletir melhorias no jogo ou mudanças em funcionalidades. Alterações significativas serão comunicadas por atualização do aplicativo.
